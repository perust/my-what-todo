# My Task

머릿속에 뭉쳐 있는 일을 실행 단위로 쪼개서 관리하는 1인용 할 일 웹 앱입니다.
백엔드 없이 브라우저의 LocalStorage에만 저장하며, `index.html`을 열면 바로 실행됩니다.

## 주요 기능

- **2단계 계층** — 상위 할 일을 하위 할 일로 쪼갭니다. 완료 상태가 위아래로 전파됩니다
- **우선순위 0~3** — 0이 가장 높습니다. 제목 앞에 `!`를 붙이면 0으로 들어갑니다
- **태그** — 제목 끝에 `#태그`를 붙여 그 자리에서 분류합니다. 항목당 5개까지
- **카테고리** — 기본 3종으로 시작하고, 톱니바퀴에서 직접 만들고 지웁니다
- **검색과 필터** — 제목·태그 실시간 검색. 카테고리·태그 필터와 함께 걸립니다
- **정렬 5종** — 우선순위 · 직접 순서 · 생성일 · 카테고리 · 완료 상태.
  직접 순서일 때는 끌어서 옮기거나 `Alt+↑`/`Alt+↓`로 옮깁니다
- **진행률** — 하위가 있는 상위는 세지 않고, 실제로 할 일인 항목만 셉니다
- **내보내기 / 가져오기** — JSON 파일로 백업하고 되돌립니다
- **다크 모드** — OS 설정을 따르다가, 고르면 그 선택을 지킵니다
- **실행 취소** — 삭제하면 5초 동안 되돌릴 수 있습니다
- **여러 탭 안전** — 다른 탭의 변경을 따라가고, 낡은 상태로는 덮어쓰지 않습니다

## 실행 방법

정적 파일뿐이라 브라우저에서 바로 엽니다.

```bash
git clone https://github.com/perust/my-task-todo.git
cd my-task-todo
open index.html
```

로컬 서버로 띄우려면:

```bash
python3 -m http.server 8000
```

## 기술 스택

HTML + CSS + JavaScript(ES2020+)만 씁니다. npm 패키지, 프레임워크, 빌드 도구,
외부 CDN 요청이 하나도 없습니다. 오프라인에서도 그대로 동작합니다.

- 저장소: `localStorage` (키 하나, 스키마 버전 3)
- 접근성: 전 기능 키보드 조작, 색 외에 텍스트·숫자로도 구분
- 성능: 항목 1000개 기준 초기 로드 45ms, 조작 반응 10ms 이내
- 지원 브라우저: 최신 버전의 Chrome, Edge, Safari, Firefox
