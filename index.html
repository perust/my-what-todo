    회차집중휴식
    분 단위로 1에서 180까지
    0%

    !로 시작하면 우선순위 0, 끝에 #태그

        도움말

        빠른 입력

        !로 시작
        우선순위 0으로 추가합니다. 우측에 선택된 우선순위에 관계 없이 추가됩니다.
        # 입력
        #으로 태그를 추가할 수 있습니다. 항목당 5개까지 추가할 수 있습니다.
        + 버튼
        하위 할 일을 추가합니다.

        우선순위

        0 · 1 · 2 · 3
        0이 가장 높은 우선순위입니다. 선택하지 않으면 1로 추가됩니다.
        숫자 클릭
        누를 때마다 0 → 1 → 2 → 3 순으로 바뀝니다. 변경하면 목록이 다시 정렬됩니다.

        필터와 검색

        카테고리 · 태그
        한 번에 하나만 적용됩니다. 다른 것을 선택하면 이전 선택은 해제됩니다.
        검색
        제목과 태그에서 함께 검색합니다. 카테고리나 태그 필터와 같이 사용할 수 있습니다.
        진행률
        하위 할 일이 있는 항목은 진행률에서 제외됩니다. 하위 할 일만 계산합니다.

        정렬

        정렬 기준
        우선순위, 직접 순서, 생성일, 카테고리, 완료 상태 중에서 선택할 수 있습니다.
        순서 변경
        정렬 기준이 직접 순서일 때만 끌어서 옮길 수 있습니다. 같은 단계의 항목끼리만 이동합니다.

        뽀모도로

        토마토 아이콘
        오른쪽 위 아이콘으로 타이머를 열고 닫습니다. 닫아도 계속 돌아갑니다.
        사이클
        집중과 휴식을 네 번 반복합니다. 1~3회차는 짧게 쉬고 4회차 뒤에는 길게 쉽니다. 한 구간이 끝나면 다음 구간이 이어서 시작됩니다.
        단일 타이머
        25 · 5 · 15분 중에서 고르거나 1분에서 180분 사이로 직접 입력합니다.
        설정 (톱니바퀴)
        회차마다 집중 시간과 휴식 시간을 바꿀 수 있습니다.
        펼치기 (화살표)
        원형 시계를 엽니다. 시간이 흐른 만큼 색이 채워집니다.
        진행 확인
        돌아가는 동안 브라우저 탭 제목에 남은 시간이 표시됩니다. 끝나면 소리로 알립니다.

        단축키

        Alt + N
        할 일 입력창으로 이동합니다.
        Alt + 1~9
        카테고리 탭을 순서대로 선택합니다. 1번은 전체입니다.
        Alt + ↑ ↓
        직접 순서일 때 선택한 항목을 위아래로 이동합니다.
