        도움말

        빠른 입력

        !로 시작
        우선순위 0으로 추가합니다. 우측에 선택된 우선순위에 관계 없이 추가됩니다.
        # 입력
        제목 끝에 #을 붙이면 태그가 됩니다. 항목당 5개까지 추가할 수 있습니다.
        + 버튼
        상위 할 일 아래에 입력칸이 열립니다. 한 번 더 누르면 닫힙니다. 입력칸 옆의 추가 버튼이나 Enter로 넣고, 넣은 뒤에도 칸이 남아 연달아 적을 수 있습니다. × 를 누르거나 Esc를 누르면 닫힙니다.

        우선순위

        0 · 1 · 2 · 3
        0이 가장 높은 우선순위입니다. 선택하지 않으면 1로 추가됩니다.
        숫자 클릭
        숫자를 누르면 그 자리에서 0부터 3까지 고를 수 있습니다. 고르면 바로 바뀌고 목록이 다시 정렬됩니다. Esc를 누르면 바뀌기 전으로 돌아갑니다.

        카테고리

        카테고리 배지
        상위 할 일 우측에 있는 배지를 누르면 그 자리에서 카테고리를 고를 수 있습니다. 고르면 바로 바뀌고, Esc를 누르면 바뀌기 전으로 돌아갑니다.
        하위 할 일
        하위 할 일은 상위 할 일의 카테고리를 그대로 따릅니다. 상위를 바꾸면 하위도 함께 바뀝니다.
        톱니바퀴
        카테고리를 만들고 지웁니다. 이름을 누르면 그 자리에서 고칠 수 있습니다. 카테고리는 64개까지 만들 수 있습니다.

        필터와 검색

        카테고리 · 태그
        한 번에 하나만 적용됩니다. 다른 것을 선택하면 이전 선택은 해제됩니다. 선택한 태그가 없어지면 전체 목록으로 돌아오고, 그 사실을 화면 아래에서 알려줍니다.
        검색
        제목과 태그에서 함께 검색합니다. 카테고리나 태그 필터와 같이 사용할 수 있습니다.
        진행률
        하위 할 일을 가진 항목은 진행률에서 빠지고, 하위가 없는 항목만 셉니다. 하위를 만들지 않았다면 모든 항목이 진행률에 들어갑니다.

        정렬

        정렬 기준
        우선순위, 직접 순서, 생성일, 카테고리, 완료 상태 중에서 선택할 수 있습니다.
        순서 변경
        정렬 기준이 직접 순서일 때만 끌어서 옮길 수 있습니다. 상위 할 일은 상위 할 일끼리, 하위 할 일은 같은 상위에 속한 것끼리만 이동합니다. 마우스 없이 Alt와 위아래 화살표로도 옮길 수 있습니다.

        뽀모도로

        토마토 아이콘
        오른쪽 위 아이콘으로 타이머를 열고 닫습니다. 닫아도 계속 돌아갑니다.
        사이클
        집중과 휴식을 네 번 반복합니다. 1~3회차는 짧게 쉬고 4회차 뒤에는 길게 쉽니다.
        구간 넘기기
        한 구간이 끝나면 타이머가 00:00에서 멈추고, 그 자리에 휴식 시작 버튼이 생깁니다. 그 버튼을 눌러야 다음 구간이 시작됩니다. 자리를 비운 사이에 끝났더라도 버튼은 그대로 기다립니다.
        단일 타이머
        25 · 5 · 15분 중에서 고르거나 1분에서 180분 사이로 직접 입력합니다. 지금 무엇으로 돌아갈지는 켜진 버튼으로 알 수 있습니다. 직접 입력했을 때는 설정 버튼이 켜집니다.
        설정 (톱니바퀴)
        회차마다 집중 시간과 휴식 시간을 바꿀 수 있습니다.
        펼치기 (화살표)
        원형 시계를 엽니다. 시간이 흐른 만큼 색이 채워집니다.
        타이머 닫기
        타이머 안에 포커스가 있을 때 Esc를 누르면 닫힙니다. 설정이나 원형 시계가 열려 있으면 그것이 먼저 닫힙니다.
        진행 확인
        돌아가는 동안 브라우저 탭 제목에 남은 시간이 표시됩니다. 끝나면 소리로 알립니다.
        미니 타이머
        타이머가 걸려 있는 동안 패널을 닫으면 화면 오른쪽 아래에 반투명한 미니 타이머가 남습니다. 돌아가는 중이든 일시정지 중이든 다음 구간을 기다리는 중이든 뜹니다. 눌러서 패널을 다시 열 수 있고, 기다리는 중이라면 여기서 바로 이어갈 수 있습니다. × 를 누르면 거두어지고, 패널을 다시 열면 되살아납니다. 얼마나 진하게 보일지는 설정(톱니바퀴)의 불투명도에서 정하며, 손잡이를 만지는 동안에는 그 자리에 미리 보여줍니다. 고른 값은 저장됩니다.
        창으로 빼기
        Chrome과 Edge에서는 타이머를 작은 별도 창으로 뺄 수 있습니다. 그 창은 다른 창 위에 계속 떠 있어서 브라우저를 최소화해도 보입니다. 시간이 흐른 만큼 채워지는 원형 시계 안에 남은 시간과 누를 버튼이 함께 들어 있고(시작·일시정지·다음 구간으로 세 가지), 오른쪽 위 버튼으로 숫자만 보는 방식으로 바꿀 수 있습니다. 창을 낮게 줄이면 버튼이 시계 오른쪽으로 나와 자리를 아끼고, 숫자만 보기에서는 한 줄로 눕습니다. 고른 방식은 저장됩니다. 창 크기는 가장자리를 끌어서 맞추시면 되고, 시계가 그 크기를 따라 커지고 작아집니다. 가로 최소 크기는 브라우저가 정해서 더 줄이지 못하고, 이 창을 반투명하게 만들 수도 없습니다. 지원하지 않는 브라우저에서는 이 버튼이 나타나지 않습니다.
        새로고침
        돌아가던 자리에서 이어집니다. 탭을 닫으면 사라집니다.

        단축키

        Alt + N
        할 일 입력창으로 이동합니다.
        Alt + 1~9
        카테고리 탭을 순서대로 선택합니다. 1번은 전체입니다.
        Alt + ↑ ↓
        직접 순서일 때 선택한 항목을 위아래로 이동합니다.

        저장 위치
        모든 데이터는 이 브라우저에만 저장됩니다. 외부로 전송되지 않습니다.
        로그인

        내보내기 · 가져오기
        목록 아래 버튼으로 JSON 파일을 저장하거나 불러올 수 있습니다. 가져오기는 되돌릴 수 없으므로 백업을 먼저 하시는 것을 권합니다.
        파일 연결
        지원 브라우저에서는 고른 JSON 파일에 현재 데이터를 바로 쓰고, 이 페이지를 닫을 때까지 이후 변경도 자동 저장합니다. 목록 아래에서 연결 파일과 마지막 성공 저장 시각을 확인할 수 있습니다. 연결 뒤 외부 변경을 감지하면 자동 저장을 멈추고, 충돌 해결에서 앱 내용으로 덮어쓰거나 외부 파일을 그대로 유지할 수 있습니다. 지원하지 않는 브라우저에서는 내보내기와 가져오기를 이용할 수 있습니다.
        Markdown 연결
        Markdown 외부 변경을 감지하면 exact bytes 보호가 자동 저장을 멈춥니다. 충돌 해결에서는 앱 내용으로 덮어쓰기, 외부 파일 유지뿐 아니라 지원되는 기존 할 일 편집의 개수 미리보기를 확인하고 가져올 수 있습니다. 체크박스·P0~P3·제목·태그·형제 순서·기존 카테고리 이동·최대 2단계 재배치만 지원하며, 추가·삭제·카테고리 CRUD·기타·설정·임의 Markdown은 거부합니다. Store와 LocalStorage를 먼저 바꾸고 JSON과 Markdown mirror는 독립적으로 저장하며, 연결은 현재 페이지를 닫을 때까지만 유지됩니다.
        문의하기
        목록 아래 문의하기 버튼으로 제목과 내용을 적으면, 그 내용이 채워진 채로 메일 앱이 열립니다. 이 앱이 직접 보내지는 않으니 메일 앱에서 한 번 더 보내기를 눌러주셔야 합니다. 할 일 내용은 함께 담기지 않습니다.

        JSON 파일 충돌 해결

        연결한 파일이 앱 밖에서 바뀌어 자동 저장을 멈췄습니다. 앱의 최신 내용으로 덮어쓰거나, 외부 파일을 쓰지 않고 연결을 해제할 수 있습니다.

        Markdown 파일 충돌 해결

        연결한 Markdown 파일이 앱 밖에서 바뀌어 자동 저장을 멈췄습니다. 앱이 생성한 정본에서 지원되는 기존 할 일 편집만 가져올 수 있습니다.
